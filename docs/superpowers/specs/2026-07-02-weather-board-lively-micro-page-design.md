# Home 天气板 Lively 微型天气页设计

记录时间：2026-07-02

## 背景

当前 Home 左侧天气板已经具备天气数据、趋势图、5 日预报、指标卡和天气环境音，但视觉上仍像一个灰色工具面板。用户在可视化伴随页中选择了 A 方向：把左侧天气板优化为 Lively Weather 风格的“微型天气页”，在不改变 Mineradio 主页整体信息架构的前提下，提高天气板的主视觉、层级和可读性。

## 目标

- 左侧天气板第一眼更像完整天气 App，而不是普通数据面板。
- 核心天气内容在第一屏尽量可见，减少内部滚动条带来的工具感。
- 趋势图更像天气模块：柔和面积、固定图标行、干净时间轴，默认不强行标注当前点。
- 5 日预报和指标卡更清晰，点击后反馈明显。
- 底部操作收敛，天气音量不常驻占位。

## 非目标

- 不把整个 Home 改成全屏天气 App。
- 不重做右侧音乐推荐卡和歌单内容。
- 不引入第三方天气图标、Lottie 或声音资源。
- 不改变后端天气接口和现有天气缓存策略。

## 设计方案

### 1. 天气板整体

给 Home 左侧天气卡增加明确的天气页姿态：更强的天气氛围底色、更少灰色平铺、更清晰的顶部 Hero。温度、城市、天气状态作为主视觉，体感、湿度、风、降水等信息保持胶囊形式，但降低拥挤感。

### 2. 内容布局

天气板内部按以下顺序组织：

1. 当前天气 Hero：温度、城市、状态、体感/湿度/风/降水。
2. 天气提醒条：一行短提示。
3. 趋势图：更大的曲线卡，默认不显示当前点椭圆/竖线，只在 hover/click 后显示选中值。
4. 5 日预报：增强选中态和图标可见性。
5. 2x3 或 3x2 指标卡：按当前可用高度自适应，优先保证卡片完整显示。
6. 操作区：天气电台、切换城市、播放器控制台、天气音、进入动态歌词。

### 3. 趋势图

趋势图保留现有 SVG 实现，但视觉上减少工程控件感：

- 线宽保持细，但面积层更柔和。
- 默认不展示第一个点的数值标签和选中竖线。
- 只有用户 hover/click 某个小时后显示对应值。
- 天气图标继续固定在横坐标下方。

### 4. 每日预报和指标卡

每日卡要更像天气 App 里的日预报：日期、星期、图标、描述、降水概率、高低温层级更明确。指标卡继续使用现有仪表绘制，但加强玻璃层次、压缩无关文字，确保 6 张卡不被底部裁切。

### 5. 天气环境音

天气音仍默认关闭。天气音量不再作为常驻长滑杆占据按钮行，改为天气音按钮附近的小浮层或 hover/focus 展开控件。播放音乐时继续降低天气环境音量。

## 文件边界

- `public/index.html`：增加天气页 class，调整天气音控件结构，保留现有 DOM id。
- `public/home-weather-ui.js`：调整趋势图默认选中显示逻辑。
- `public/styles/app.css`：重写天气板局部布局、趋势图、日卡、指标卡和天气音控件样式。
- `tests/smoke.test.js`：增加天气页结构、无内部滚动、天气音浮层和趋势图默认不标注的断言。

## 验收标准

- Home 左侧天气板不再出现明显内部滚动条。
- 天气板顶部当前天气更强，灰色工具面板感降低。
- 默认趋势图不再在第一个小时显示竖线和数值标签；hover/click 后才出现。
- 5 日预报、6 个指标卡和底部按钮在 1920x1080 截图中不被裁切。
- 天气音量滑杆不再常驻占据底部按钮行。
- `npm run check`、`npm test`、`git diff --check` 通过。
